# 立体 C の可視化

座標空間内の回転体（通過領域）の問題を、Three.js で 3D 表示する Web アプリです。
回転角や断面の位置をスライダーで動かしながら、立体の形と断面積・体積を確かめられます。

## 問題

座標平面で

$$(x-1)^2+y^2\le 1,\quad 0\le x\le 1,\quad y\ge 0$$

の表す領域を **A** とする。

- **B**：A を座標空間内で $z$ 軸の方向に 1 だけ平行移動するとき、A が通過してできる立体
- **C**：B を $x$ 軸のまわりに $90^\circ$ 回転したときにできる立体（B が通過する部分）

## 解釈と計算

### 回転の向き

$x$ 軸まわりの回転は $yz$ 平面内で起こるので、本アプリでは
**$y$ 軸の正の向きから $z$ 軸の正の向きへ回す**と解釈しています。

### 断面

平面 $x=k\ (0\le k\le 1)$ で切ると、

- A の断面は長さ $r=\sqrt{2k-k^2}$ の線分です。
- B の断面は横 $r$、縦 $1$ の長方形 $[0,r]\times[0,1]$（$yz$ 平面）です。
- C の断面は、この長方形を原点まわりに $0$ から $\theta$ まで回したときに通過する領域です。次の 3 つに分けられます。
  1. 元の長方形の対角線より下の直角三角形（面積 $\frac{r}{2}$）
  2. 半径 $\sqrt{r^2+1}$、中心角 $\theta$ の扇形（面積 $\frac{\theta(1+r^2)}{2}$）
  3. 回転後の長方形の対角線より上の直角三角形（面積 $\frac{r}{2}$）

したがって断面積は

$$S(k)=r+\frac{\theta(1+r^2)}{2},\qquad r^2=2k-k^2$$

### 体積

$$
V(\theta)=\int_0^1 S(k)\,dk
=\underbrace{\int_0^1\sqrt{2k-k^2}\,dk}_{=\pi/4}
+\frac{\theta}{2}\underbrace{\int_0^1(1+2k-k^2)\,dk}_{=5/3}
=\frac{\pi}{4}+\frac{5}{6}\theta
$$

$\theta=\frac{\pi}{2}$ のとき

$$V=\frac{\pi}{4}+\frac{5\pi}{12}=\boxed{\frac{2}{3}\pi}\approx 2.0944$$

## 使い方

1. `index.html` を任意のフォルダに保存します。
2. ブラウザ（Chrome / Edge / Firefox / Safari の最新版）で開きます。

ビルドやサーバーは不要です。ただし、ライブラリを CDN から読み込むため**インターネット接続が必要**です。

> ブラウザの設定によってはローカルファイルでの ES Modules 読み込みが制限されることがあります。
> その場合は、`python -m http.server` などでローカルサーバーを立てて `http://localhost:8000/` から開いてください。

## 操作方法

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 視点の回転 |
| ホイール | 拡大・縮小 |
| 右ドラッグ | 平行移動 |
| 回転角 θ スライダー | B の回転角（0°〜90°）を変更 |
| ▶ 再生 / ❚❚ 停止 | θ を 0°↔90° で往復アニメーション |
| θ=0 ボタン | θ を 0° に戻す（再生も停止） |
| 表示チェックボックス | 各立体の表示・非表示の切り替え |
| C の不透明度 | C の透明度を調整 |
| 断面 x スライダー | 断面 $x=k$ の位置を変更 |

## 画面の見方

| 色 | 対象 |
| --- | --- |
| 赤 | 領域 A（$xy$ 平面上の 1/4 円） |
| 青（半透明） | 元の位置の B |
| 緑 | 角度 θ まで回転した B |
| オレンジ | C（回転角 0〜θ の通過領域）。θ=90° のときが問題の立体 |

## 実装メモ

- 立体は $x$ 方向に断面多角形を並べてメッシュ化しています（`buildSolid`）。
  分割数は定数 `M`（$x$ 方向）と `N`（断面の各区間）で調整できます。
- C の断面の境界は `profileC(r, T)` で計算しています。
  「元の長方形の辺 → 半径 $\sqrt{r^2+1}$ の円弧 → 回転後の長方形の辺」の順につないでいます。
- 回転は関数 `rot` で行います。

## カスタマイズ

### 回転の向きを逆にする（$y$ 軸から $-z$ の向き、など）

`rot` 関数の符号を変更します。

```js
// 現在：y → z の向き
const rot=([y,z],t)=>[y*Math.cos(t)-z*Math.sin(t), y*Math.sin(t)+z*Math.cos(t)];
// 逆向き
const rot=([y,z],t)=>[y*Math.cos(t)+z*Math.sin(t), -y*Math.sin(t)+z*Math.cos(t)];
```

なお、`profileC` は「y → z の向き」を前提にしています。
向きを変える場合は、`profileC` 内の角度も合わせて反転させてください。
体積は回転の向きによらず $\frac{2}{3}\pi$ です（断面が対称な配置になるため）。

### 精度・速度の調整

再生時に動作が重い場合は、`M` や `N` の値を小さくしてください。
